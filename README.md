# Словочит

Читалка для изучения английского: нажмите на слово в книге и увидите перевод, транскрипцию, форму слова и примеры. Есть словарь с карточками, уроки по основам и прогресс. Всё работает без интернета.

**Как установить на iPhone или iPad:** откройте сайт в Safari → «Поделиться» → «На экран Домой».

Разбор слов в контексте с помощью Claude включается своим ключом API в Профиле. Без ключа приложение работает полностью, кроме этой кнопки.
